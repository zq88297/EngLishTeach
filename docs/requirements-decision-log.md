## 最终实现基线

- 两宗可自由切换的 7 章案件，整个产品游戏化。
- Phaser 负责实时世界，React 负责可访问的对话、输入、账号和数据界面。
- 虚拟摇杆探索，NPC 中文意图加英文拼写；倒计时归零只触发剧情后果，不降低掌握度。
- 三次最差选择进入失败结局，但 FSRS 和记忆记录永久保留。
- 自适应陷阱基于用户真实错误，所有内容由作者预先编写并经结构校验。
- 免费、无广告、无生成式 AI、无性别推断、无血腥内容。

详细的学习证据、内容规格、状态规则、隐私同步、无障碍和验收要求以 docs/product-requirements.md 为准。若本日志中的早期决定与该文档冲突，以下“对抗性审查修订”以及产品需求文档优先。

## 对抗性审查修订

| ID | 原漏洞 | 修订后的最终决定 |
| --- | --- | --- |
| A-001 | 只以完成七章判断成功 | 同时设置延迟学习效果、七章完成率、事件完整性、恢复率和无障碍门槛；首轮阈值作为封闭测试假设。 |
| A-002 | 超时被记录为错词 | 超时只影响剧情，不更新 FSRS，不建立用户易混关系；失焦和系统故障不影响剧情或掌握度。 |
| A-003 | 听力和阅读只有范围名称 | 每章必须包含听力场景、阅读证物和基于英语材料的剧情推理，第七章使用未见语境综合测试。 |
| A-004 | 中文提示可能对应多个英文答案 | 学习项目按词元和义项标识，内容显式声明可接受词形与同义表达，拒绝答案必须可解释。 |
| A-005 | 七天、漏学和案件切换规则不清 | 七天定义为七次建议学习会话，不强制连续；案件进度独立，学习掌握共享，复习按真实时间调度。 |
| A-006 | 自适应陷阱没有冷启动门槛 | 冷启动使用审校后的通用陷阱；两个不同语境出现知识错误后才建立用户级易混关系。 |
| A-007 | 重试可能重复制造学习证据 | 重试保留学习事件并更换语境；同一语境连续重试只产生一条调度证据，内容不足时解析后继续。 |
| A-008 | PWA 同步冲突和离线丢失未定义 | 学习事件只追加并使用 eventId 幂等同步；剧情冲突要求用户选择，不允许静默覆盖。 |
| A-009 | 未成年人、隐私和删除权未定义 | 最小化收集，提供导出和删除；公开测试前必须明确数据区域、跨境路径和备份保留期。 |
| A-010 | 无障碍停留在原则 | 核心路径提供 DOM 替代操作、字幕、计时关闭和人工辅助技术验收，不能只依赖 Phaser 画布。 |
| A-011 | Zod 无法保证教学质量 | 增加英语、教学、陷阱、剧情、无障碍和目标用户试玩审校门槛。 |
| A-012 | 两案结束后的长期承诺不清 | MVP 只承诺到期复习、案件回顾和总部陈列，不承诺持续新剧情。 |
